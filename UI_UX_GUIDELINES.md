# UX/UI

O usuário deve sentir que está evoluindo durante toda a jornada.

Toda ação precisa ter feedback.

Loading.

Success.

Error.

Empty State.

Skeleton.

Toast.

Confirmação.

---

Sempre manter:

Espaçamento consistente.

Tipografia limpa.

Boa hierarquia.

Microinterações.

Acessibilidade.

Contraste adequado.

Navegação intuitiva.

Nunca sobrecarregar a interface.
