# Coding Standards

Sempre utilizar:

TypeScript Strict.

ESLint.

Prettier.

Importações organizadas.

Sem any.

Sem código duplicado.

Funções pequenas.

Componentes pequenos.

Responsabilidade única.

Nomes claros.

Comentários apenas quando agregarem valor.

Criar hooks reutilizáveis.

Criar services.

Criar utils.

Criar constantes.

Criar types.

Sempre pensar em escalabilidade.
