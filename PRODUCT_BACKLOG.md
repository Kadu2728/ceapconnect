# Definição de Pronto (Definition of Done)

Uma funcionalidade só é considerada concluída quando:

✔ Funciona corretamente.

✔ É responsiva.

✔ Está tipada.

✔ Possui tratamento de erro.

✔ Possui loading.

✔ Possui estado vazio.

✔ Possui feedback visual.

✔ Segue o Design System.

✔ Segue a arquitetura.

✔ Não possui código duplicado.

✔ Passa no lint.

✔ Está documentada.

✔ Está pronta para produção.

Nunca considerar uma feature pronta apenas porque "funciona".
